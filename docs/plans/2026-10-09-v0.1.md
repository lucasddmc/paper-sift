# paper-sift v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Claude Code plugin whose `/paper-sift:survey` skill turns a topic into a ranked, explained reading list, using the Semantic Scholar citation graph and TypeSafe's Jev.

**Architecture:** A skill drives the conversation and calls one Python CLI (`scripts/survey.py`) through Bash. The CLI is a thin layer over a standard-library package (`scripts/paper_sift/`): HTTP clients for Jev, Semantic Scholar and OpenAlex, a whitelisted policy-expression evaluator, and one module per pipeline stage. Every stage writes to the survey directory and resumes when re-run. A read-only subagent does the optional blind check.

**Tech Stack:** Python ≥ 3.9 standard library; `pypdf>=4` installed on demand into a private venv; `unittest`; Claude Code plugin format (skills, agents, marketplace).

**Spec:** `docs/design.md` (read it first; this plan implements it).

## Global Constraints

- Python ≥ 3.9. Standard library only, except `pypdf>=4`, installed on first full-text run into `<data dir>/venv`. No pytest, no requests.
- Tests: `python3 -m unittest discover -s tests -v` from the repo root. Tests never touch the network: every client takes an injectable transport or is replaced by a fake.
- Code, comments, docs and printed messages in English.
- Every HTTP request sends `User-Agent: paper-sift/<version> (+https://github.com/lucasddmc/paper-sift)`.
- Keys are never printed or logged. Lookup order: `TYPESAFE_API_KEY` / `S2_API_KEY`, then `~/.config/typesafe/key` / `~/.config/semanticscholar/key` (file mode 600, directory mode 700).
- Jev model pinned to `jev-1.13.0`. Price constant US$ 0.042 per million input tokens, always presented as an estimate.
- Pool ceiling: default 800, allowed 100–3,000. `tau` default 0.5.
- Full text: cut at the first References/Bibliography heading after 30% of the text, cap 90,000 characters, at least 2,000 usable characters. arXiv downloads spaced 3 s apart. OpenAlex serial, 0.25 s pause, title similarity ≥ 0.92.
- The CLI never prints abstracts or paper text; it prints titles, metadata and scores.
- One commit per task. Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

```python
import unittest

import helpers  # noqa: F401
from paper_sift import USER_AGENT
from paper_sift.net import AuthError, HttpError, request, request_json


def scripted(*responses):
    """A transport that returns (or raises) the given responses in order and records the calls."""
    queue, calls = list(responses), []

    def transport(method, url, headers, body, timeout):
        calls.append((method, url, headers, body))
        item = queue.pop(0)
        if isinstance(item, Exception):
            raise item
        return item

    transport.calls = calls
    return transport


class NetTest(unittest.TestCase):
    def test_returns_json_and_sends_user_agent(self):
        t = scripted((200, b'{"ok": true}'))
        self.assertEqual(request_json("POST", "https://x.test/a", payload={"q": 1}, transport=t), {"ok": True})
        method, url, headers, body = t.calls[0]
        self.assertEqual(headers["User-Agent"], USER_AGENT)
        self.assertEqual(headers["Content-Type"], "application/json")
        self.assertEqual(body, b'{"q": 1}')

    def test_retries_rate_limits_and_network_errors(self):
        waits = []
        t = scripted((429, b""), (529, b""), OSError("reset"), (200, b"[]"))
        self.assertEqual(request_json("GET", "https://x.test", transport=t, sleep=waits.append), [])
        self.assertEqual(waits, [2.0, 4.0, 8.0])

        waits = []
```

```python
"""Small HTTP layer: JSON payloads, retries with exponential backoff, and an injectable transport.

A transport is any callable `transport(method, url, headers, body, timeout) -> (status, body_bytes)`;
tests pass fakes, production uses urllib.
"""
import json
import time
import urllib.error
import urllib.request

from . import USER_AGENT

RETRY_STATUSES = {429, 500, 502, 503, 504, 529}


class HttpError(Exception):
    def __init__(self, status, body=b"", url=""):
        self.status, self.body, self.url = status, body, url
        super().__init__(f"HTTP {status} from {url}: {body[:300]!r}")


class AuthError(HttpError):
    """401 or 403: the key is missing, wrong or revoked."""


def urllib_transport(method, url, headers, body, timeout):
    req = urllib.request.Request(url, data=body, headers=headers, method=method)
    try:
        with urllib.request.urlopen(req, timeout=timeout) as resp:
            return resp.status, resp.read()
    except urllib.error.HTTPError as e:
        return e.code, e.read()


def request(method, url, *, headers=None, payload=None, transport=None, retries=8, sleep=time.sleep,
            timeout=90, max_wait=60.0):
    """Return the response body. Retries RETRY_STATUSES and network errors; raises AuthError or HttpError."""
    transport = transport or urllib_transport
    hdrs = {"User-Agent": USER_AGENT, **(headers or {})}
    body = None
    if payload is not None:
        body = json.dumps(payload).encode()
        hdrs["Content-Type"] = "application/json"
    wait = 2.0
    for attempt in range(retries + 1):
        try:
            status, data = transport(method, url, hdrs, body, timeout)
        except OSError as e:  # URLError, timeouts, refused connections
            status, data = None, repr(e).encode()
        if status is not None and 200 <= status < 300:
            return data
        if status in (401, 403):
            raise AuthError(status, data, url)
        if status is not None and status not in RETRY_STATUSES:
            raise HttpError(status, data, url)
        if attempt == retries:
            raise HttpError(status or 0, data, url)
        sleep(min(wait, max_wait))
        wait *= 2


def request_json(method, url, **kwargs):
    return json.loads(request(method, url, **kwargs))
```

```python
"""Where API keys live: an environment variable first, then a file only the user can read."""
import os
import pathlib

SERVICES = {
    "typesafe": ("TYPESAFE_API_KEY", (".config", "typesafe", "key")),
    "s2": ("S2_API_KEY", (".config", "semanticscholar", "key")),
}


def key_path(service, home=None):
    _, parts = SERVICES[service]
    return pathlib.Path(home or pathlib.Path.home()).joinpath(*parts)


def get_key(service, env=None, home=None):
    env = os.environ if env is None else env
    var, _ = SERVICES[service]
    value = (env.get(var) or "").strip()
    if value:
        return value
    path = key_path(service, home)
    if path.exists():
        return path.read_text().strip() or None
    return None


def save_key(service, value, home=None):
    value = value.strip()
    if not value:
        raise ValueError("empty key")
    path = key_path(service, home)
    path.parent.mkdir(parents=True, exist_ok=True)
    os.chmod(path.parent, 0o700)
    fd = os.open(path, os.O_WRONLY | os.O_CREAT | os.O_TRUNC, 0o600)
    with os.fdopen(fd, "w") as f:
        f.write(value)
    os.chmod(path, 0o600)
    return path
```

`scripts/paper_sift/jev.py`:

```python
"""TypeSafe Jev client. paper-sift only asks Noul questions (probability that the answer is yes)."""
import time

from .net import request_json

ENDPOINT = "https://api.typesafe.ai/v1/systemone"
DEFAULT_MODEL = "jev-1.13.0"
PRICE_PER_MTOK = 0.042  # USD per million input tokens, output free; published price, September 2026


def nouls(questions):
    """{name: {instructions, true, false, ...}} -> the API's question map."""
    return {name: {"type": "noul", "instructions": q["instructions"],
                   "criteria": {"true": q["true"], "false": q["false"]}}
            for name, q in questions.items()}


def ask(state, questions, *, key, model=DEFAULT_MODEL, transport=None, sleep=time.sleep, retries=8, timeout=60):
    """One call with every question (fan-out). Returns {"answers": {name: P(yes)}, "tokens", "model"}."""
    body = request_json("POST", ENDPOINT, headers={"Authorization": f"Bearer {key}"},
                        payload={"model": model, "state": state, "questions": nouls(questions)},
                        transport=transport, sleep=sleep, retries=retries, timeout=timeout)
    return {"answers": {name: float(body["answers"][name]["noul"]) for name in questions},
            "tokens": int((body.get("usage") or {}).get("input_tokens", 0)),
            "model": body.get("model") or model}


def check_key(key, *, model=DEFAULT_MODEL, transport=None, sleep=time.sleep):
    """The smallest useful call. Returns the model that answered; raises AuthError for a rejected key."""
    probe = {"probe": {"instructions": "Is `text` about the sky?", "true": "Yes", "false": "No"}}
    return ask({"text": "The sky is blue."}, probe, key=key, model=model, transport=transport, sleep=sleep,
               retries=2, timeout=30)["model"]


def cost(tokens):
    return tokens / 1_000_000 * PRICE_PER_MTOK
```

### Task 5: Semantic Scholar client

**Files:**
- Create: `scripts/paper_sift/s2.py`
- Test: `tests/test_s2.py`

**Interfaces:**
- Consumes: `net.request_json`
- Produces:
  - `API`, `REC_API`, `FIELDS = "paperId,title,abstract,year,venue,externalIds,citationCount,publicationTypes"`, `EDGE_CAP = 10_000`, `BATCH = 500`
  - `class S2(key=None, transport=None, sleep=time.sleep, pause=1.1, retries=10)` with:
    - `search(query, limit=100, fields=FIELDS) -> list[dict]`
    - `batch(ids, fields=FIELDS) -> list[dict | None]` (same order as `ids`)
    - `edges(paper_id, relation) -> list[dict]` (`relation` in `"citations"`, `"references"`)

```python
"""Semantic Scholar Graph API client: search, batch lookup, citation edges, recommendations."""
import time
import urllib.parse

from .net import request_json

API = "https://api.semanticscholar.org/graph/v1"
REC_API = "https://api.semanticscholar.org/recommendations/v1/papers/"
FIELDS = "paperId,title,abstract,year,venue,externalIds,citationCount,publicationTypes"
EDGE_CAP = 10_000  # S2 serves at most this many citations or references per paper
BATCH = 500


class S2:
    def __init__(self, key=None, transport=None, sleep=time.sleep, pause=1.1, retries=10):
        self.key, self.transport, self.sleep = key, transport, sleep
        self.pause, self.retries = pause, retries

    def _call(self, method, url, payload=None):
        headers = {"x-api-key": self.key} if self.key else {}
        data = request_json(method, url, headers=headers, payload=payload, transport=self.transport,
                            sleep=self.sleep, retries=self.retries)
        self.sleep(self.pause)  # stay under the per-second rate limit
        return data

    def search(self, query, limit=100, fields=FIELDS):
        q = urllib.parse.urlencode({"query": query, "limit": min(limit, 100), "fields": fields})
        return [p for p in self._call("GET", f"{API}/paper/search?{q}").get("data") or [] if p.get("paperId")]

    def batch(self, ids, fields=FIELDS):
        out = []
        for i in range(0, len(ids), BATCH):
            out += self._call("POST", f"{API}/paper/batch?fields={fields}", {"ids": list(ids[i:i + BATCH])})
        return out

    def edges(self, paper_id, relation):
        if relation not in ("citations", "references"):
            raise ValueError(f"unknown relation {relation!r}")
        key = "citingPaper" if relation == "citations" else "citedPaper"
        out, offset = [], 0
        while offset < EDGE_CAP:
            limit = min(1000, EDGE_CAP - offset)
            page = self._call("GET", f"{API}/paper/{paper_id}/{relation}?fields={FIELDS}&limit={limit}&offset={offset}")
            out += [e[key] for e in page.get("data") or [] if (e.get(key) or {}).get("paperId")]
            if "next" not in page or not page.get("data"):
                break
            offset = page["next"]
        return out

    def recommendations(self, positive_ids, limit=500):
        data = self._call("POST", f"{REC_API}?fields={FIELDS}&limit={limit}",
                          {"positivePaperIds": list(positive_ids)})
        return [p for p in data.get("recommendedPapers") or [] if p.get("paperId")]
```

```python
"""OpenAlex fallback for abstracts that Semantic Scholar does not serve. Called serially:
parallel requests were refused in testing."""
import difflib
import re
import time
import urllib.parse

from .net import HttpError, request_json

API = "https://api.openalex.org/works"
MIN_SIMILARITY = 0.92


def _norm(s):
    return re.sub(r"[^a-z0-9 ]", "", (s or "").lower())


def title_similarity(a, b):
    return difflib.SequenceMatcher(None, _norm(a), _norm(b)).ratio()


def rebuild(inverted_index):
    positions = sorted((i, word) for word, idxs in inverted_index.items() for i in idxs)
    return " ".join(word for _, word in positions)


def find_abstract(title, *, transport=None, sleep=time.sleep):
    q = urllib.parse.urlencode({"search": title, "per-page": 3, "select": "title,abstract_inverted_index"})
    try:
        results = request_json("GET", f"{API}?{q}", transport=transport, sleep=sleep, retries=3,
                               timeout=30).get("results") or []
    except HttpError:
        return None
    for work in results:
        if work.get("abstract_inverted_index") and title_similarity(work.get("title"), title) >= MIN_SIMILARITY:
            return rebuild(work["abstract_inverted_index"])
    return None
```

`scripts/paper_sift/policy.py`:

```python
"""Policy expressions over Jev facts and paper metadata.

Parsed with `ast` against a whitelist and evaluated by walking the tree; nothing reaches eval().
A bare fact name means "probability >= tau"; `p.<fact>` is the probability itself; `importance`,
`year` and `citations` are paper metadata. Missing facts count as probability 0.
"""
import ast

VARIABLES = ("importance", "year", "citations")

_BIN = {ast.Add: lambda a, b: a + b, ast.Sub: lambda a, b: a - b,
        ast.Mult: lambda a, b: a * b, ast.Div: lambda a, b: a / b if b else 0.0}
_CMP = {ast.Lt: lambda a, b: a < b, ast.LtE: lambda a, b: a <= b, ast.Gt: lambda a, b: a > b,
        ast.GtE: lambda a, b: a >= b, ast.Eq: lambda a, b: a == b, ast.NotEq: lambda a, b: a != b}


class PolicyError(ValueError):
    pass


class Expr:
    def __init__(self, source, facts):
        self.source, self.facts = source, frozenset(facts)
        try:
            self.tree = ast.parse(source, mode="eval").body
        except SyntaxError as e:
            raise PolicyError(f"cannot parse {source!r}: {e.msg}") from None
        self._check(self.tree)

    def __call__(self, record, tau):
        return self._eval(self.tree, record, tau)

    def _check(self, node):
        if isinstance(node, ast.BoolOp):
            children = node.values
        elif isinstance(node, ast.UnaryOp) and isinstance(node.op, (ast.Not, ast.USub)):
            children = [node.operand]
        elif isinstance(node, ast.BinOp) and type(node.op) in _BIN:
            children = [node.left, node.right]
        elif isinstance(node, ast.Compare) and all(type(op) in _CMP for op in node.ops):
            children = [node.left, *node.comparators]
        elif isinstance(node, ast.Constant) and type(node.value) in (bool, int, float):
            children = []
        elif isinstance(node, ast.Name) and (node.id in self.facts or node.id in VARIABLES):
            children = []
        elif (isinstance(node, ast.Attribute) and isinstance(node.value, ast.Name)
              and node.value.id == "p" and node.attr in self.facts):
            children = []
        else:
            raise PolicyError(f"{ast.unparse(node)!r} is not allowed in {self.source!r}")
        for child in children:
            self._check(child)

    def _eval(self, node, r, tau):
        if isinstance(node, ast.BoolOp):
            values = (self._eval(v, r, tau) for v in node.values)
            return all(values) if isinstance(node.op, ast.And) else any(values)
        if isinstance(node, ast.UnaryOp):
            value = self._eval(node.operand, r, tau)
            return (not value) if isinstance(node.op, ast.Not) else -value
        if isinstance(node, ast.BinOp):
            return _BIN[type(node.op)](float(self._eval(node.left, r, tau)), float(self._eval(node.right, r, tau)))
        if isinstance(node, ast.Compare):
            left = self._eval(node.left, r, tau)
            for op, comparator in zip(node.ops, node.comparators):
                right = self._eval(comparator, r, tau)
                if not _CMP[type(op)](left, right):
                    return False
                left = right
            return True
        if isinstance(node, ast.Constant):
            return node.value
        if isinstance(node, ast.Name):
            value = float(r.get(node.id) or 0.0)
            return value >= tau if node.id in self.facts else value
        return float(r.get(node.attr) or 0.0)  # p.<fact>
```

```python
"""Load and validate a survey's spec.json."""
import hashlib
import json
import pathlib
import re

from .policy import VARIABLES, Expr, PolicyError

POOL_MIN, POOL_MAX, POOL_DEFAULT = 100, 3000, 800
RECIPES = ("learn-area",)
NAME = re.compile(r"^[a-z][a-z0-9_]*$")
SLUG = re.compile(r"^[a-z0-9]+(?:-[a-z0-9]+)*$")
DEFAULTS = {
    "version": 1, "recipe": "learn-area", "model": "jev-1.13.0", "tau": 0.5, "years": None,
    "pool_size": POOL_DEFAULT, "queries": [],
    "sources": {"citations": True, "references": True, "recommendations": True, "search_per_query": 100},
    "fulltext_questions": {},
    "policy": {"gate": "topic", "priority": "p.topic * importance",
               "fulltext": {"top": 30, "per_subtopic": 5, "include_seeds": True},
               "start_here": "False", "final_rank": "p.topic", "final_top": 20},
}


class SpecError(ValueError):
    pass


def question_hash(q):
    text = "\x1f".join((q["instructions"], q["true"], q["false"]))
    return hashlib.sha256(text.encode()).hexdigest()[:12]


def subtopics(spec):
    return [name for name in spec["questions"] if name.startswith("sub_")]


def _merge(defaults, given):
    out = dict(defaults)
    for k, v in given.items():
        out[k] = _merge(out[k], v) if isinstance(v, dict) and isinstance(out.get(k), dict) else v
    return out


def _check_questions(questions, where):
    if not isinstance(questions, dict):
        raise SpecError(f"{where} must be an object")
    for name, q in questions.items():
        if not NAME.match(name) or name == "p" or name in VARIABLES:
            raise SpecError(f"{where}: invalid name {name!r} (lowercase letters, digits and _; "
                            f"not 'p' or {', '.join(VARIABLES)})")
        for field in ("instructions", "true", "false"):
            if not isinstance(q.get(field), str) or not q[field].strip():
                raise SpecError(f"{where}.{name}: missing {field!r}")


def validate(raw):
    spec = _merge(DEFAULTS, raw)
    if spec["version"] != 1:
        raise SpecError("version must be 1")
    if spec["recipe"] not in RECIPES:
        raise SpecError(f"recipe must be one of {', '.join(RECIPES)}")
    if not isinstance(spec.get("slug"), str) or not SLUG.match(spec["slug"]):
        raise SpecError("slug must be lowercase words joined by '-'")
    if not isinstance(spec.get("area"), str) or len(spec["area"].strip()) < 40:
        raise SpecError("area must describe the area and the reader in a few sentences")
    tau = spec["tau"]
    if isinstance(tau, bool) or not isinstance(tau, (int, float)) or not 0 < tau < 1:
        raise SpecError("tau must be between 0 and 1")
    seeds = spec.get("seeds")
    if not isinstance(seeds, list) or not seeds or not all(isinstance(s, dict) and isinstance(s.get("id"), str)
                                                          for s in seeds):
        raise SpecError("seeds must be a non-empty list of {id, title, why}")
    if not isinstance(spec["queries"], list) or not all(isinstance(q, str) and q.strip() for q in spec["queries"]):
        raise SpecError("queries must be a list of strings")
    n = spec["pool_size"]
    if isinstance(n, bool) or not isinstance(n, int) or not POOL_MIN <= n <= POOL_MAX:
        raise SpecError(f"pool_size must be an integer from {POOL_MIN} to {POOL_MAX} (got {n!r})")
    years = spec["years"]
    if years is not None and not (isinstance(years, list) and len(years) == 2
                                  and all(isinstance(y, int) for y in years) and years[0] <= years[1]):
        raise SpecError("years must be null or [first, last]")
    per_query = spec["sources"].get("search_per_query")
    if isinstance(per_query, bool) or not isinstance(per_query, int) or not 0 <= per_query <= 100:
        raise SpecError("sources.search_per_query must be an integer from 0 to 100")
    if "questions" not in spec:
        raise SpecError("questions missing")
    _check_questions(spec["questions"], "questions")
    if "topic" not in spec["questions"]:
        raise SpecError("questions must include 'topic', the gate question")
    _check_questions(spec["fulltext_questions"], "fulltext_questions")
    clash = set(spec["questions"]) & set(spec["fulltext_questions"])
    if clash:
        raise SpecError(f"names used in both question sets: {sorted(clash)}")
    policy = spec["policy"]
    abstract = list(spec["questions"])
    everything = abstract + list(spec["fulltext_questions"])
    for key, facts in (("gate", abstract), ("priority", abstract), ("start_here", everything),
                       ("final_rank", everything)):
        try:
            Expr(policy[key], facts)
        except PolicyError as e:
            raise SpecError(f"policy.{key}: {e}") from None
    for key in ("top", "per_subtopic"):
        value = policy["fulltext"].get(key)
        if isinstance(value, bool) or not isinstance(value, int) or value < 0:
            raise SpecError(f"policy.fulltext.{key} must be a non-negative integer")
    final_top = policy["final_top"]
    if isinstance(final_top, bool) or not isinstance(final_top, int) or final_top < 1:
        raise SpecError("policy.final_top must be a positive integer")
    return spec


def load(path):
    path = pathlib.Path(path)
    try:
        raw = json.loads(path.read_text())
    except (OSError, json.JSONDecodeError) as e:
        raise SpecError(f"cannot read {path}: {e}") from None
    return validate(raw)
```

```python
"""Files of a survey directory. JSON everywhere; the pool is gzipped; scores are append-only lines."""
import gzip
import json
import pathlib

FILES = {
    "spec": "spec.json", "pool": "pool.json.gz", "scores": "scores.jsonl", "fulltext": "fulltext.json",
    "sample": "validation/sample.json", "sample_key": "validation/key.json", "labels": "validation/labels.json",
    "validation": "validation/result.json", "report": "report.md", "bib": "reading-list.bib", "csv": "scored.csv",
}


class Survey:
    def __init__(self, directory):
        self.dir = pathlib.Path(directory)

    def path(self, name):
        return self.dir / FILES[name]

    def exists(self, name):
        return self.path(name).exists()

    def read(self, name, default=None):
        p = self.path(name)
        if not p.exists():
            return default
        data = p.read_bytes()
        return json.loads(gzip.decompress(data) if p.suffix == ".gz" else data)

    def write(self, name, obj):
        p = self.path(name)
        p.parent.mkdir(parents=True, exist_ok=True)
        data = json.dumps(obj, ensure_ascii=False, indent=1).encode()
        tmp = p.with_name(p.name + ".tmp")
        tmp.write_bytes(gzip.compress(data) if p.suffix == ".gz" else data)
        tmp.replace(p)

    def read_lines(self, name):
        p = self.path(name)
        if not p.exists():
            return []
        return [json.loads(line) for line in p.read_text().splitlines() if line.strip()]

    def append_lines(self, name, rows):
        p = self.path(name)
        p.parent.mkdir(parents=True, exist_ok=True)
        with p.open("a") as f:
            for row in rows:
                f.write(json.dumps(row, ensure_ascii=False) + "\n")

    def write_text(self, name, text):
        p = self.path(name)
        p.parent.mkdir(parents=True, exist_ok=True)
        p.write_text(text)
```

```python
"""Candidate pool: seeds, their citation neighborhood, recommendations and keyword search."""
import bisect
import time


def add(pool, paper, via):
    """Insert or merge a paper; `via` records which source found it."""
    entry = pool.get(paper["paperId"])
    if entry is None:
        entry = pool[paper["paperId"]] = {**paper, "via": []}
    elif not entry.get("abstract") and paper.get("abstract"):
        entry["abstract"] = paper["abstract"]
    if via not in entry["via"]:
        entry["via"].append(via)
    return entry


def connectivity(paper):
    return sum(1 for v in paper.get("via", []) if v != "seed")


def set_importance(papers):
    """Citation percentile among papers of the same year (mid-rank, 0..1): recent papers are not
    buried under older, more-cited ones."""
    by_year = {}
    for p in papers:
        by_year.setdefault(p.get("year"), []).append(p.get("citationCount") or 0)
    for counts in by_year.values():
        counts.sort()
    for p in papers:
        counts = by_year[p.get("year")]
        c = p.get("citationCount") or 0
        less, upto = bisect.bisect_left(counts, c), bisect.bisect_right(counts, c)
        p["importance"] = round((less + 0.5 * (upto - less)) / len(counts), 4)


def in_years(paper, years):
    return years is None or paper.get("year") is None or years[0] <= paper["year"] <= years[1]


def trim(papers, size):
    """Keep every seed, then the best-connected papers (ties: importance). Returns (kept, trimmed)."""
    seeds = [p for p in papers if "seed" in p["via"]]
    rest = sorted((p for p in papers if "seed" not in p["via"]),
                  key=lambda p: (-connectivity(p), -p.get("importance", 0.0), p["paperId"]))
    room = max(size - len(seeds), 0)
    return seeds + rest[:room], rest[room:]


def collect(spec, s2, *, log=print):
    found = s2.batch([s["id"] for s in spec["seeds"]])
    pool, seeds, missing = {}, [], []
    for given, paper in zip(spec["seeds"], found):
        if not paper or not paper.get("paperId"):
            missing.append(given["id"])
            log(f"seed not found on Semantic Scholar: {given['id']}")
            continue
        seeds.append(paper)
        add(pool, paper, "seed")
    if not seeds:
        raise ValueError("none of the seeds was found on Semantic Scholar")
    src = spec["sources"]
    for n, seed in enumerate(seeds, 1):
        name = (seed.get("title") or seed["paperId"])[:60]
        for relation, label, wanted in (("citations", "cites", src["citations"]),
                                        ("references", "cited-by", src["references"])):
            if wanted:
                got = s2.edges(seed["paperId"], relation)
                log(f"seed{n} {name}: {len(got)} {relation}")
                for p in got:
                    add(pool, p, f"{label}:seed{n}")
    if src["recommendations"]:
        got = s2.recommendations([s["paperId"] for s in seeds])
        log(f"recommendations: {len(got)}")
        for p in got:
            add(pool, p, "recommended")
    if src["search_per_query"]:
        for i, query in enumerate(spec["queries"], 1):
            got = s2.search(query, limit=src["search_per_query"])
            log(f"query{i} {query!r}: {len(got)}")
            for p in got:
                add(pool, p, f"query:{i}")
    candidates = [p for p in pool.values() if "seed" in p["via"] or in_years(p, spec["years"])]
    set_importance(candidates)
    kept, trimmed = trim(candidates, spec["pool_size"])
    return {"seeds": [{"paperId": s["paperId"], "title": s.get("title")} for s in seeds],
            "missing_seeds": missing,
            "stats": {"found": len(pool), "outside_years": len(pool) - len(candidates),
                      "candidates": len(candidates), "kept": len(kept), "trimmed": len(trimmed)},
            "papers": kept,
            "trimmed": [{"paperId": p["paperId"], "title": p.get("title"), "via": p["via"]} for p in trimmed]}


def fill_abstracts(papers, find_abstract, *, log=print, sleep=time.sleep, pause=0.25, every=50):
    """Serial OpenAlex lookups for papers without an abstract. Returns (found, looked_up)."""
    missing = [p for p in papers if not p.get("abstract")]
    found = 0
    for i, p in enumerate(missing, 1):
        text = find_abstract(p.get("title") or "")
        if text:
            p["abstract"], p["abstract_source"] = text, "openalex"
            found += 1
        sleep(pause)
        if i % every == 0:
            log(f"OpenAlex: {i}/{len(missing)} looked up, {found} found")
    return found, len(missing)
```

`scripts/paper_sift/screen.py`:

```python
"""Abstract stage: ask the spec's questions of every pool paper that has an abstract.

scores.jsonl is append-only. Each row holds the answers of one call plus a hash of each question's
text; `current` folds the rows and drops answers to questions edited since.
"""
from concurrent.futures import ThreadPoolExecutor

from .net import AuthError
from .spec import question_hash


def current(rows, questions):
    hashes = {name: question_hash(q) for name, q in questions.items()}
    out = {}
    for row in rows:
        if "error" in row:
            continue
        entry = out.setdefault(row["paperId"], {"answers": {}, "tokens": 0, "model": None})
        entry["tokens"] += row.get("tokens", 0)
        entry["model"] = row.get("model") or entry["model"]
        for name, prob in row["answers"].items():
            if name in hashes and row.get("hashes", {}).get(name) == hashes[name]:
                entry["answers"][name] = prob
    return out


def pending(papers, done, questions):
    """[(paper, questions still to ask)] for papers that have an abstract."""
    work = []
    for paper in papers:
        if not paper.get("abstract"):
            continue
        have = done.get(paper["paperId"], {}).get("answers", {})
        need = {name: q for name, q in questions.items() if name not in have}
        if need:
            work.append((paper, need))
    return work


def score(work, spec, ask, *, sink, workers=16, log=print, every=100):
    """Ask in parallel; every row goes to sink(row) as it arrives. Returns (ok, errors)."""
    def one(item):
        paper, need = item
        state = {"area": spec["area"],
                 "paper": {"title": paper.get("title") or "", "abstract": paper["abstract"]}}
        try:
            out = ask(state, need)
        except AuthError:
            raise
        except Exception as e:  # recorded; the next run retries it
            return {"paperId": paper["paperId"], "error": repr(e)[:300]}
        return {"paperId": paper["paperId"], "answers": out["answers"], "tokens": out["tokens"],
                "model": out["model"], "hashes": {name: question_hash(q) for name, q in need.items()}}

    errors = 0
    with ThreadPoolExecutor(workers) as executor:
        for i, row in enumerate(executor.map(one, work), 1):
            sink(row)
            errors += "error" in row
            if i % every == 0:
                log(f"scored {i}/{len(work)}")
    return len(work) - errors, errors
```

```python
"""Apply a spec's policy: gate, priority, full-text selection and the final reading list."""
from .policy import Expr
from .spec import subtopics


def records(papers, scores, questions):
    """Pool metadata plus current answers, for papers answered on every question. Abstracts stay out."""
    out = []
    for paper in papers:
        answers = scores.get(paper["paperId"], {}).get("answers", {})
        if not all(name in answers for name in questions):
            continue
        rec = {k: v for k, v in paper.items() if k != "abstract"}
        rec.update(answers)
        rec["citations"] = paper.get("citationCount") or 0
        out.append(rec)
    return out


def label(spec, name):
    q = spec["questions"].get(name) or spec["fulltext_questions"].get(name) or {}
    return q.get("label") or name.removeprefix("sub_").replace("_", " ")


class Policy:
    def __init__(self, spec):
        self.spec, self.tau = spec, spec["tau"]
        policy = spec["policy"]
        abstract = list(spec["questions"])
        everything = abstract + list(spec["fulltext_questions"])
        self.gate = Expr(policy["gate"], abstract)
        self.priority = Expr(policy["priority"], abstract)
        self.start_here = Expr(policy["start_here"], everything)
        self.final_rank = Expr(policy["final_rank"], everything)

    def passing(self, recs):
        return [r for r in recs if self.gate(r, self.tau)]

    def by_priority(self, recs):
        return sorted(recs, key=lambda r: (-float(self.priority(r, self.tau)), r["paperId"]))

    def for_fulltext(self, recs, seed_ids):
        """Seeds, the top papers by priority, and the top papers of each subtopic, without duplicates."""
        ft = self.spec["policy"]["fulltext"]
        passing = self.by_priority(self.passing(recs))
        chosen = {}
        if ft["include_seeds"]:
            for r in recs:
                if r["paperId"] in seed_ids:
                    chosen[r["paperId"]] = r
        for r in passing[:ft["top"]]:
            chosen.setdefault(r["paperId"], r)
        for sub in subtopics(self.spec):
            for r in [x for x in passing if x.get(sub, 0.0) >= self.tau][:ft["per_subtopic"]]:
                chosen.setdefault(r["paperId"], r)
        return self.by_priority(chosen.values())

    def reading_list(self, recs):
        """[(section, records)]: Start here, then subtopics taking turns, then the rest; final_top in all."""
        cap = self.spec["policy"]["final_top"]
        ordered = sorted(recs, key=lambda r: (-float(self.final_rank(r, self.tau)), r["paperId"]))
        used, sections = set(), []

        def room():
            return cap - len(used)

        start = [r for r in ordered if self.start_here(r, self.tau)][:max(room(), 0)]
        used.update(r["paperId"] for r in start)
        if start:
            sections.append(("Start here", start))
        subs = subtopics(self.spec)
        queues = {s: [r for r in ordered if r.get(s, 0.0) >= self.tau] for s in subs}
        picks = {s: [] for s in subs}
        moved = True
        while room() > 0 and moved:
            moved = False
            for s in subs:
                queue = queues[s]
                while queue and queue[0]["paperId"] in used:
                    queue.pop(0)
                if queue and room() > 0:
                    r = queue.pop(0)
                    picks[s].append(r)
                    used.add(r["paperId"])
                    moved = True
        sections += [(label(self.spec, s), picks[s]) for s in subs if picks[s]]
        rest = [r for r in ordered if r["paperId"] not in used][:max(room(), 0)]
        if rest:
            sections.append(("Also worth reading", rest))
        return sections
```

```python
"""Optional blind check of the abstract gate. Runs only after the user agrees to its cost."""
import math
import random


def draw(recs, passed_ids, *, n_rejected=30, n_accepted=15, seed=42):
    """Shuffled sample ids and the subset the gate rejected. Deterministic for a given seed."""
    rejected = sorted(r["paperId"] for r in recs if r["paperId"] not in passed_ids)
    accepted = sorted(r["paperId"] for r in recs if r["paperId"] in passed_ids)
    rng = random.Random(seed)
    pick_rejected = rng.sample(rejected, min(n_rejected, len(rejected)))
    pick_accepted = rng.sample(accepted, min(n_accepted, len(accepted)))
    order = pick_rejected + pick_accepted
    rng.shuffle(order)
    return order, set(pick_rejected)


def binomial_cdf(k, n, p):
    return sum(math.comb(n, i) * p ** i * (1 - p) ** (n - i) for i in range(k + 1))


def upper_bound(k, n, alpha=0.05):
    """One-sided Clopper-Pearson upper bound for a rate, after k events in n trials."""
    if n == 0 or k >= n:
        return 1.0
    lo, hi = k / n, 1.0
    for _ in range(60):
        mid = (lo + hi) / 2
        if binomial_cdf(k, n, mid) > alpha:
            lo = mid
        else:
            hi = mid
    return hi


def compare(order, rejected_ids, labels):
    """labels: {paperId: "relevant" | "not_relevant"} from the blind labeler."""
    checked = [i for i in order if i in labels]
    rejected = [i for i in checked if i in rejected_ids]
    accepted = [i for i in checked if i not in rejected_ids]
    missed = [i for i in rejected if labels[i] == "relevant"]
    false_pass = [i for i in accepted if labels[i] != "relevant"]
    agree = len(checked) - len(missed) - len(false_pass)
    return {
        "checked": len(checked),
        "unlabeled": [i for i in order if i not in labels],
        "agreement": round(agree / len(checked), 4) if checked else None,
        "rejected_checked": len(rejected),
        "missed": missed,
        "miss_rate_upper95": round(upper_bound(len(missed), len(rejected)), 4) if rejected else None,
        "accepted_checked": len(accepted),
        "false_pass": false_pass,
        "precision": round(1 - len(false_pass) / len(accepted), 4) if accepted else None,
        "disagreements": (missed + false_pass)[:8],
    }
```

```python
"""Paper text for Jev: extract with pypdf, cut at the references, cap the length."""
import re

MAX_CHARS = 90_000  # about 25k tokens, inside Jev's 32k state limit
MIN_CHARS = 2_000   # less usually means a scanned PDF or a failed extraction
_REFERENCES = re.compile(r"\n\s*(?:References|REFERENCES|Bibliography|BIBLIOGRAPHY)\s*\n")


def cut_references(text):
    """Cut at the first references heading after 30% of the text (drops appendices too)."""
    for match in _REFERENCES.finditer(text):
        if match.start() > 0.3 * len(text):
            return text[:match.start()], True
    return text, False


def prepare(text, max_chars=MAX_CHARS):
    body, was_cut = cut_references(text)
    return body[:max_chars], was_cut, len(text)


def extract(pdf_path):
    from pypdf import PdfReader  # installed on demand by deps.ensure_pypdf
    reader = PdfReader(str(pdf_path))
    return "\n".join(page.extract_text() or "" for page in reader.pages)
```

```python
        raise RuntimeError(f"could not install {REQUIREMENT} ({e}). Install it with "
                           f"`python3 -m pip install --user '{REQUIREMENT}'` and run the step again.") from None
```

```python
"""Full-text stage: find open PDFs, download them, and ask the full-text questions.
The text goes only to Jev; nothing here prints it."""
import pathlib
import time
from concurrent.futures import ThreadPoolExecutor

from .net import AuthError, HttpError, request
from .pdftext import MIN_CHARS, prepare
from .spec import question_hash


def lookup(recs, s2):
    """{paperId: {"url": PDF url or None, "authors": [names]}}. arXiv first, then S2's open-access link."""
    if not recs:
        return {}
    info = s2.batch([r["paperId"] for r in recs], fields="authors,openAccessPdf")
    out = {}
    for rec, meta in zip(recs, info):
        meta = meta or {}
        arxiv = (rec.get("externalIds") or {}).get("ArXiv")
        url = f"https://arxiv.org/pdf/{arxiv}" if arxiv else (meta.get("openAccessPdf") or {}).get("url")
        out[rec["paperId"]] = {"url": url or None,
                               "authors": [a["name"] for a in meta.get("authors") or [] if a.get("name")]}
    return out


def download(url, dest, *, transport=None, sleep=time.sleep):
    """The cached or freshly downloaded PDF, or None when the URL does not serve a PDF."""
    dest = pathlib.Path(dest)
    if dest.exists() and dest.read_bytes()[:4] == b"%PDF":
        return dest
    try:
        data = request("GET", url, transport=transport, sleep=sleep, retries=2, timeout=90)
    except HttpError:
        return None
    if data[:4] != b"%PDF":
        return None
    dest.parent.mkdir(parents=True, exist_ok=True)
    dest.write_bytes(data)
    return dest


def ask_text(rec, text, spec, ask):
    """Ask the full-text questions; on an HTTP error retry once with half the text."""
    questions = spec["fulltext_questions"]
    last = None
    for size in (len(text), len(text) // 2):
        state = {"area": spec["area"], "paper": {"title": rec.get("title") or "", "text": text[:size]}}
        try:
            out = ask(state, questions)
        except AuthError:
            raise
        except HttpError as e:
            last = e
            continue
        return {"answers": out["answers"], "tokens": out["tokens"], "model": out["model"], "chars": size,
                "hashes": {name: question_hash(q) for name, q in questions.items()}}
    return {"error": repr(last)[:300]}


def run(selected, spec, s2, ask, cache, done, *, extract, transport=None, sleep=time.sleep, log=print, workers=6):
    """Results by paperId with status read | no_pdf | no_text | error."""
    hashes = {name: question_hash(q) for name, q in spec["fulltext_questions"].items()}
    results = dict(done)
    todo = [r for r in selected
            if not (done.get(r["paperId"], {}).get("status") == "read"
                    and done[r["paperId"]].get("hashes") == hashes)]
    meta = lookup(todo, s2)
    texts = {}
    for r in todo:
        pid, info = r["paperId"], meta[r["paperId"]]
        base = {"url": info["url"], "authors": info["authors"]}
        path = pathlib.Path(cache) / f"{pid}.pdf"
        fresh = not path.exists()
        got = download(info["url"], path, transport=transport, sleep=sleep) if info["url"] else None
        if info["url"] and fresh:
            sleep(3.0 if "arxiv.org" in info["url"] else 1.0)  # arXiv asks for 3 s between requests
        if not got:
            results[pid] = {**base, "status": "no_pdf"}
            log(f"no open PDF: {(r.get('title') or pid)[:70]}")
            continue
        try:
            body, was_cut, total = prepare(extract(got))
        except Exception as e:  # broken or encrypted PDF
            results[pid] = {**base, "status": "no_text", "error": repr(e)[:200]}
            continue
        if len(body.strip()) < MIN_CHARS:
            results[pid] = {**base, "status": "no_text", "chars_pdf": total}
            continue
        texts[pid] = (r, body, base, was_cut, total)

    def one(item):
        pid, (r, body, base, was_cut, total) = item
        out = ask_text(r, body, spec, ask)
        return pid, {**base, "status": "error" if "error" in out else "read", "cut_references": was_cut,
                     "chars_pdf": total, **out}

    with ThreadPoolExecutor(workers) as executor:
        for pid, res in executor.map(one, texts.items()):
            results[pid] = res
    return results
```

```python
"""report.md, reading-list.bib and scored.csv. Titles, metadata and scores only; never abstracts."""
import csv
import io
import re

from .jev import cost
from .pool import connectivity
from .ranking import label


def link(r):
    ids = r.get("externalIds") or {}
    if ids.get("ArXiv"):
        return f"https://arxiv.org/abs/{ids['ArXiv']}"
    if ids.get("DOI"):
        return f"https://doi.org/{ids['DOI']}"
    return f"https://www.semanticscholar.org/paper/{r['paperId']}"


def why(r, spec):
    """The facts that put a paper on the list."""
    tau = spec["tau"]
    parts = [f"{name} {r[name]:.2f}" for name in spec["fulltext_questions"] if name in r]
    parts += [label(spec, name) for name in spec["questions"] if name != "topic" and r.get(name, 0.0) >= tau]
    parts.append(f"importance {r.get('importance', 0.0):.2f}")
    return " · ".join(parts)


def _pct(x):
    return "n/a" if x is None else f"{x:.0%}"


def render(spec, ctx):
    models = ", ".join(sorted(ctx["models"])) or spec["model"]
    s = ctx["stats"]
    read = sum(1 for v in ctx["fulltext"].values() if v.get("status") == "read")
    listed = sum(len(recs) for _, recs in ctx["sections"])
    funnel = [("candidates found", s["found"]), ("outside the year range", s["outside_years"]),
              (f"kept in the pool (ceiling {spec['pool_size']:,})", s["kept"]),
              ("with an abstract", ctx["with_abstract"]), ("scored by Jev", ctx["scored"]),
              (f"passed the gate (`{spec['policy']['gate']}`)", ctx["passed"]),
              ("selected for full text", len(ctx["selected"])), ("full text read", read),
              ("in the reading list", listed)]
    out = [f"# Reading list: {spec['slug']}", "", f"_{ctx['date']} · paper-sift · {models}_", "",
           "## Area", "", spec["area"], "", "## Funnel", "", "| stage | papers |", "|---|---:|"]
    out += [f"| {name} | {n:,} |" for name, n in funnel]
    out += ["", "## Reading list", ""]
    n = 0
    for title, recs in ctx["sections"]:
        out += [f"### {title}", ""]
        for r in recs:
            n += 1
            venue = f", {r['venue']}" if r.get("venue") else ""
            out += [f"{n}. **{r.get('title')}** ({r.get('year') or 'n.d.'}{venue}). [link]({link(r)})",
                    f"   {why(r, spec)} · found by {', '.join(r.get('via', []))}"]
        out.append("")
    out += ["## Seeds", ""] + [f"- seed{i}: {seed.get('title')}" for i, seed in enumerate(ctx["seeds"], 1)] + [""]
    if ctx["no_pdf"] or ctx["no_abstract"]:
        out += ["## Check by hand", ""]
        if ctx["no_pdf"]:
            out += ["Selected for full text, but no open PDF could be read:", ""]
            out += [f"- {r.get('title')} ({r.get('year') or 'n.d.'}). [link]({link(r)})" for r in ctx["no_pdf"]]
            out.append("")
        if ctx["no_abstract"]:
            out += ["Found by several sources but without an abstract, so never screened:", ""]
            out += [f"- {p.get('title')} ({p.get('year') or 'n.d.'}), {connectivity(p)} sources. [link]({link(p)})"
                    for p in ctx["no_abstract"]]
            out.append("")
    v = ctx.get("validation")
    if v and v["checked"]:
        out += ["## Blind check of the gate", "",
                f"A separate reader labeled {v['checked']} abstracts without seeing the scores. Agreement: "
                f"{_pct(v['agreement'])}. Relevant papers among the {v['rejected_checked']} rejected: "
                f"{len(v['missed'])}, so at most {_pct(v['miss_rate_upper95'])} of the rejected papers are likely "
                f"relevant (95% upper bound). Precision among the accepted: {_pct(v['precision'])}. The labels "
                "come from Claude, not from ground truth, and a sample this size catches gross failures only.", ""]
    tokens = ctx["tokens_abstract"] + ctx["tokens_fulltext"]
    out += ["## Cost", "", f"{ctx['tokens_abstract']:,} Jev tokens on abstracts and {ctx['tokens_fulltext']:,} on "
            f"full text: about US$ {cost(tokens):.2f} at the published price.", ""]
    return "\n".join(out)


def _bib_key(r, used):
    authors = r.get("authors") or []
    last = re.sub(r"[^a-z]", "", (authors[0].split()[-1] if authors else "anon").lower()) or "anon"
    words = (r.get("title") or "paper").split() or ["paper"]
    first = re.sub(r"[^a-z]", "", words[0].lower()) or "paper"
    base = f"{last}{r.get('year') or ''}{first}"
    key, n = base, 1
    while key in used:
        n += 1
        key = f"{base}{n}"
    used.add(key)
    return key


def bibtex(recs):
    used, entries = set(), []
    for r in recs:
        ids = r.get("externalIds") or {}
        title = (r.get("title") or "").replace("{", "").replace("}", "")
        fields = [("title", "{" + title + "}"), ("author", " and ".join(r.get("authors") or [])),
                  ("year", r.get("year")), ("howpublished", r.get("venue")), ("doi", ids.get("DOI")),
                  ("eprint", ids.get("ArXiv")), ("archiveprefix", "arXiv" if ids.get("ArXiv") else None),
                  ("url", link(r))]
        body = ",\n".join(f"  {k} = {{{v}}}" for k, v in fields if v)
        entries.append(f"@misc{{{_bib_key(r, used)},\n{body}\n}}")
    return "\n\n".join(entries) + "\n"


def scored_csv(recs, spec, passed_ids, fulltext):
    names = list(spec["questions"]) + list(spec["fulltext_questions"])
    buf = io.StringIO()
    writer = csv.writer(buf)
    writer.writerow(["paperId", "title", "year", "venue", "citations", "importance", "connectivity", "passed_gate",
                     "fulltext_status", *names, "link"])
    for r in recs:
        ft = fulltext.get(r["paperId"], {})
        answers = {**r, **ft.get("answers", {})}
        writer.writerow([r["paperId"], r.get("title"), r.get("year"), r.get("venue"), r.get("citations"),
                         r.get("importance"), connectivity(r), r["paperId"] in passed_ids, ft.get("status", ""),
                         *["" if answers.get(n) is None else round(answers[n], 4) for n in names], link(r)])
    return buf.getvalue()
```

```python
from .spec import subtopics

ABSTRACT_TOKENS = 350     # a typical title and abstract
FULLTEXT_TOKENS = 22_000  # a typical paper body after the 90k-character cap
QUESTION_OVERHEAD = 20    # per question, beyond its text
OPENALEX_SHARE = 0.4      # guess: share of pool papers without an S2 abstract
OPENALEX_SECONDS = 0.75   # one serial lookup, pause included
S2_SECONDS = 1.5          # one S2 request with the pause; much more when rate-limited


def tokens_of(text):
    return len(text) // 4 + 1


def question_tokens(questions):
    return sum(tokens_of(q["instructions"] + q["true"] + q["false"]) + QUESTION_OVERHEAD
               for q in questions.values())


def estimate(spec, *, have_s2_key):
    area = tokens_of(spec["area"])
    pool = spec["pool_size"]
    ft = spec["policy"]["fulltext"]
    n_text = 0
    if spec["fulltext_questions"]:
        n_text = ((len(spec["seeds"]) if ft["include_seeds"] else 0) + ft["top"]
                  + ft["per_subtopic"] * len(subtopics(spec)))
    tok_abstract = pool * (area + ABSTRACT_TOKENS + question_tokens(spec["questions"]))
    tok_text = n_text * (area + FULLTEXT_TOKENS + question_tokens(spec["fulltext_questions"]))
    requests = len(spec["seeds"]) * 2 * 2 + len(spec["queries"]) + 2
    collect_lo = (requests * S2_SECONDS + pool * OPENALEX_SHARE * OPENALEX_SECONDS) / 60
    collect_hi = collect_lo * (2 if have_s2_key else 4)
    return {"pool_size": pool, "fulltext_max": n_text, "tokens_abstract": tok_abstract, "tokens_fulltext": tok_text,
            "cost_usd": round(cost(tok_abstract + tok_text), 3),
            "minutes": {"collect": [round(collect_lo, 1), round(collect_hi, 1)],
                        "score": round(pool / 16 / 60 + 0.5, 1),
                        "fulltext": round(n_text * 4.5 / 60 + 0.5, 1)}}
```

```python
    """Everything report.render needs, plus `recs` and `passed_ids` for the exports."""
    data, _, recs = scored_records(survey, spec)
    policy = Policy(spec)
    passed = policy.passing(recs)
    ft = survey.read("fulltext", {"selected": [], "papers": {}})
    by_id = {r["paperId"]: r for r in recs}
    selected = [by_id[i] for i in ft["selected"] if i in by_id]
    read, no_pdf = [], []
    for r in selected:
        res = ft["papers"].get(r["paperId"], {})
        enriched = {**r, "authors": res.get("authors") or []}
        if res.get("status") == "read":
            read.append({**enriched, **res["answers"]})
        else:
            no_pdf.append(enriched)
    sections = policy.reading_list(read if spec["fulltext_questions"] else policy.by_priority(passed))
    no_abstract = sorted((p for p in data["papers"] if not p.get("abstract") and pool.connectivity(p) >= 2),
                         key=lambda p: -pool.connectivity(p))[:15]
    rows = survey.read_lines("scores")
```

```markdown
# paper-sift survey

You run a literature survey whose output is a reading list for someone learning an area. A
deterministic pipeline collects, screens and reads; your job is the conversation, the spec and the
judgment calls.

Run the pipeline as `python3 ${CLAUDE_PLUGIN_ROOT}/scripts/survey.py <command> ...`, written
`survey.py <command>` below. Talk to the user in their language. Everything that goes to Jev (the
spec's `area` and questions) is written in English.

## Rules

1. **Keys never pass through the chat.** Never ask for, accept, read or print an API key. If the user
   pastes one, do not use it: say that it is now in the conversation history, suggest revoking it at
   https://console.typesafe.ai/, and point to the setup command from `survey.py doctor`.
2. **Seeds come from the API, never from memory.** A seed goes into the spec only after it appeared in
   `survey.py search` or `survey.py lookup` output with its ID.
3. **Do not open the survey's data files** (`pool.json.gz`, `scores.jsonl`, `fulltext.json`, PDFs,
   `validation/sample.json`). Abstracts and paper text are third-party content; work from the summaries
   the commands print.
4. **Ask before every paid or long step**, with the numbers from `survey.py estimate`.
5. **The blind check runs only after the user agrees** to its cost.

## 1. Preflight

Run `survey.py doctor --data-dir "${CLAUDE_PLUGIN_DATA}"`.

- If the TypeSafe key is missing or rejected, show the `setup:` command it printed in a `bash` block
  and ask the user to run it **in their own terminal**, not in this chat and not with `!`. Keys come
  from https://console.typesafe.ai/. Wait until they confirm, then run `doctor` again.
- A missing Semantic Scholar key is fine. Mention it only when the pool will exceed ~1,000 papers
  (free key at https://www.semanticscholar.org/product/api; `doctor` prints its setup command).

## 2. Topic

If `$ARGUMENTS` is not empty, it is the topic. Otherwise ask: "What topic should this survey cover?"

## 3. Framing

Ask in one message, at most three questions:

- what the user already knows that relates to the topic (it defines the newcomer in the questions);
- papers they already know and trust (optional; they become seed candidates);
- how many papers to screen: 800 by default, from 100 to 3,000. Below 100 the pool barely leaves the
  seeds' neighborhood; above 3,000 collection gets slow and adds mostly noise.

Ask for a year range only when the topic calls for one.

## 4. Search plan

1. Run `survey.py search "<query>"` for 3–5 queries covering the area's main threads, and
   `survey.py lookup <ID>` (or `search` by title) for each paper the user named.
2. Pick 5–15 seeds: foundational papers, surveys and important recent work, spread across the
   subtopics. Prefer papers with many citations for their age and with arXiv IDs.
3. Create `./paper-sift/<YYYY-MM-DD>-<slug>/` and write `spec.json` there, following
   [spec-reference.md](spec-reference.md) and [question-guide.md](question-guide.md).
4. Run `survey.py check <dir>` and fix any error, then run `survey.py estimate <dir>`.
5. Show the user, compactly: the seeds (title, year), the subtopics, the gate question, the pool size
   and the estimate. Ask for approval or changes. Run nothing paid before approval.

## 5. Collect

Run `survey.py collect <dir>`. When the pool ceiling is above ~1,000 or there is no S2 key, run it in
the background and wait for it to finish. Report the line it prints, and any seed it did not find.

## 6. Screen

Run `survey.py score <dir>`. Report how many papers were scored and how many passed the gate, and show
a few of the top titles. If calls failed, run it again: only the failures are retried.

If fewer than ~10% or more than ~90% of the scored papers pass the gate, the gate question is probably
wrong. Say so and propose a fix before going on.

## 7. Blind check (only with approval)

Offer it: a separate reader labels about 45 abstracts (30 the gate rejected, 15 it accepted) without
seeing any score; it costs roughly 20k tokens and a few minutes. Only if the user says yes:

1. Run `survey.py sample <dir>`.
2. Spawn the `paper-sift:blind-labeler` agent with only the absolute path of the sample file that
   `sample` printed. Do not give it scores, the gate rule or your expectations.
3. Save its JSON reply, exactly as returned, to the `labels.json` path that `sample` printed.
4. Run `survey.py validate <dir>`. Report the summary and show each disagreement (at most 8); ask the
   user to decide each one.
5. If the user confirms that relevant papers were rejected, propose a change to the gate question,
   apply it to `spec.json`, run `survey.py check` and `survey.py score` (only the edited question is
   asked again), and offer one more check.

## 8. Full text

Before the first run, tell the user that `pypdf` will be installed into the plugin's data directory.
Run `survey.py fulltext <dir> --data-dir "${CLAUDE_PLUGIN_DATA}"`, in the background when more than
~40 papers are selected. Report how many were read and how many had no open PDF.

## 9. Report

Run `survey.py report <dir>` and `survey.py export <dir>`. Summarize the funnel, the "Start here"
papers, one line per section, and the papers to check by hand. Give the paths of `report.md`,
`reading-list.bib` and `scored.csv`.

Then offer changes. Policy changes (for example "only papers after 2018" or "require code") are edits
to `policy` in `spec.json`, followed by `survey.py check` and `survey.py report`; they cost nothing.
Editing a question's text means running `score` or `fulltext` again, which re-asks only that question.
```

````markdown
## Expressions

- A bare question name is true when its probability is at least `tau`: `topic and not sub_hardware`.
````

```markdown
# Writing the questions

Jev answers each question with the probability that the answer is yes. It reads literally, judges one
thing at a time, and sees only the spec's `area` and one paper. These rules come from TypeSafe's
guidance (https://docs.typesafe.ai/) and from what failed in practice.

## Rules

1. **One judgment per question.** "Is it about X and does it propose Y?" is two questions; combine them
   in the policy.
2. **Say exactly what counts.** The `true` and `false` criteria must agree with the instruction; edge
   cases go there.
3. **Name the look-alikes that do not count.** When a neighboring field uses the same words, say so in
   `false`, for example: "adversarial training of GANs does NOT count as adversarial robustness".
4. **Point at the inputs by name:** `paper` (title and abstract, or full text) and `area`.
5. **No double negatives** and no questions about properties of properties.
6. **Never gate on a holistic question** such as "is this relevant to our project?" or "is this close to
   the area?". It accepts too much: one such question let through every paper that used a common
   baseline technique. Gate on what the paper is mainly about.
7. **Plain English**, with no abbreviation that `area` does not define.

## Abstract questions

- `topic` (required; the gate). Instructions: "Is `paper` mainly about <the area in a few words>, in the
  sense described in `area`?" True: "The main subject is <...>: <the kinds of contribution that count>".
  False: "The paper only uses <...> as a tool for another goal, or is about <look-alike>".
- `survey`. Instructions: "Is `paper` a survey, tutorial, taxonomy or position paper?" True: "It
  surveys, systematizes or teaches a research area rather than presenting one new method". False: "It
  presents a new method, dataset or empirical study".
- 4–8 subtopics named `sub_<name>`, each with a short `label`. Instructions: "Is `paper` about
  <subtopic>?" True: "<subtopic> is a main contribution". False: "<subtopic> is not a main
  contribution". Together they should cover the area as `area` describes it, with little overlap.

## Full-text questions (defaults; adapt the wording to the area)

| name | instructions | true | false |
|---|---|---|---|
| `didactic` | Reading the full text of `paper`: could a newcomer with the background described in `area` learn the core concepts of the area from it? | It explains its problem, background and method clearly and self-containedly; a newcomer could follow it without prior reading in the area | It assumes the reader already knows the area, or it is narrow and incremental |
| `map` | Does `paper` give the reader a map of the area described in `area`: a taxonomy, a systematic comparison of many methods, or a synthesis of what works and what does not? | A reader comes out with an overview of many methods | It covers one method or one setting |
| `formulation` | Does `paper` state its problem precisely: explicit assumptions, inputs and outputs, and a definition of success or an evaluation criterion? | The setting and the success criterion are explicit | The setting or the success criterion is left implicit |
| `limitations` | Does `paper` explicitly discuss its limitations or open problems? | Yes | No |
| `code` | Does `paper` state that its code, models or data are publicly available? | Yes | No |

With these, use `start_here` = `(survey or map) and didactic` and `final_rank` = `p.didactic`.
```

````markdown
# paper-sift

A Claude Code plugin that builds a reading list for learning a research area.

You name the topic. Claude works out a search plan with you, then runs a deterministic pipeline:

1. **Collect** candidates from the Semantic Scholar citation graph around a few seed papers, plus
   recommendations and keyword search: up to 800 papers by default.
2. **Screen** every candidate with [TypeSafe's Jev](https://docs.typesafe.ai/) on its full abstract.
   Jev answers yes/no questions ("is this mainly about the area?", "which subtopic?"), and a rule in the
   survey's spec decides which papers pass.
3. **Read** the full text of the most promising open-access papers and ask whether each one teaches the
   area well.
4. **Report** a ranked reading list ("Start here", then one section per subtopic) that says why each
   paper is on it, with `.bib` and `.csv` exports.

The main Claude session never reads abstracts or PDFs: they go to Jev. Claude works from titles,
metadata and scores.

## Install

```bash
claude plugin marketplace add lucasddmc/paper-sift
claude plugin install paper-sift@paper-sift
```

You need Python 3.9+ and a [TypeSafe API key](https://console.typesafe.ai/). A free
[Semantic Scholar API key](https://www.semanticscholar.org/product/api) is optional and helps above
~1,000 papers.

## Keys

On the first survey Claude checks for the key. If it is missing, Claude shows a command to run **in your
own terminal**, along the lines of:

```bash
python3 ~/.claude/plugins/cache/.../scripts/setup_key.py typesafe
```

It reads the key without echoing it and saves it to `~/.config/typesafe/key` with mode 600. Setting
`TYPESAFE_API_KEY` works too. Do not paste keys into the chat: Claude will refuse them, and they would
stay in the conversation history.

## Use

```
/paper-sift:survey diffusion models for image generation
```

Claude asks what you already know, which papers you trust and how many papers to screen; proposes seeds
and questions with a cost estimate; and runs each stage after you approve. Results go to
`./paper-sift/<date>-<slug>/`:

| file | contents |
|---|---|
| `report.md` | funnel, reading list, papers to check by hand, cost |
| `reading-list.bib` | the list as BibTeX |
| `scored.csv` | every screened paper with Jev's probabilities |
| `spec.json` | the survey's definition; edit `policy` and re-run the report for free |

## How it decides

The model answers facts; code applies the policy. Each question returns the probability of "yes", and
the spec's policy combines them:

```json
"policy": {"gate": "topic", "priority": "p.topic * importance", "final_rank": "p.didactic"}
```

`importance` is a paper's citation percentile among papers of the same year, so recent work is not
buried under older, more-cited papers. Changing the policy re-ranks without new inference.

Abstracts are sent whole. In a 56-paper test, cutting them at 600 characters dropped recall of the
relevant papers from 7/7 to 3/7, and lowering the threshold did not help: the deciding sentence was
not in the input. Small sample, clear mechanism.

## Optional blind check

After screening, Claude offers a blind check of the gate: a separate, read-only subagent labels about
45 abstracts (30 the gate rejected, 15 it accepted) without seeing any score. You get the agreement, an
upper bound on the share of rejected papers that were relevant, and the disagreements to judge
yourself. It costs about 20k Claude tokens, so it runs only if you say yes. The labels are Claude's,
not ground truth; a sample this size catches gross failures, not small losses.

## Cost and time

At Jev's published price (US$ 0.042 per million input tokens), 800 abstracts plus ~40 full texts cost
about US$ 0.10. Collection takes several minutes for 800 papers, mostly spent looking up missing
abstracts in OpenAlex one at a time.

## What leaves your machine

- To TypeSafe: the area description (written from your topic and background), titles, abstracts, and
  the full text of open-access papers.
- To Semantic Scholar, OpenAlex and arXiv: search queries, paper IDs and titles.
- Nothing else from your files.

## Limitations

- One recipe for now: learning an area. Novelty checks and property searches are planned.
- Only open-access full text is read; the report lists the rest for you.
- Jev reads English best, so questions are always written in English.
- Papers without an abstract on Semantic Scholar or OpenAlex are listed, not screened.
````
